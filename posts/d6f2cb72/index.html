康耐视视觉相机FTP存图完整方案（FileZilla Server+IS2800存图命名+定时清理）

发表于2026-11-28|更新于2026-11-28|工业自动化

在产线视觉检测项目中，通常需要将相机每次检测的 OK / NG 图像自动上传到工控机归档追溯，同时防止长期运行写满硬盘。本文整理了一套完整的现场闭环方案：FileZilla Server 搭建与排障 → 康耐视 IS2800 FTP 动态命名存图 → Windows 定时自动清理脚本。

一、搭建 FileZilla Server FTP 服务器

1. 启动服务与管理界面

  1. 运行 FileZilla Server.exe 启动后台服务，服务器地址（127.0.0.1）和默认管理端口保持默认：

  1. 运行 FileZilla Server Interface.exe 连接管理界面，日志区域显示 Logged on 即表示登录成功：

2. 常见启动失败排查

  • 现象 1：界面提示 Error, could not connect to server，说明后台 Server 服务尚未开启：

  • 排查方法：务必先运行 FileZilla Server.exe。正常情况下再次运行会弹窗提示 Stop Server?；如果一直提示 Start server? 而无法启动，请打开任务管理器检查 FileZilla Server 进程与服务状态：

  • 现象 2：端口冲突导致服务启动失败（需检查 21 / 管理端口是否被其他程序占用）：

  • 设为开机自动启动：在系统服务列表中找到 FileZilla Server FTP server，右键打开 属性，将 启动类型 改为 自动：

3. 添加 FTP 用户与共享目录权限

  1. 点击菜单栏上的 用户（Users） 图标，点击 Add 新建用户名，并在 General 中勾选密码设置登录密码：

  1. 切换到左侧 Shared folders，点击 Add 指定本地存图目录，勾选右侧文件及目录的 读取 / 写入 / 删除 / 追加 / 创建 / 列出 等所需权限，点击 确定 保存：

4. 设置 FTP 端口、绑定 IP 与界面自启

  1. 点击菜单栏 设置 图标，在 常规设置（General settings） 中确认或修改 FTP 监听端口（默认 21）：

  1. 切换到 IP 绑定（IP Bindings），绑定与视觉相机处于同一网段的本机 IP 地址并点击确定：

  1. 如需开机自动显示管理界面，可将 FileZilla Server Interface.exe 创建快捷方式并放入 Windows 开始菜单的 启动（Startup） 目录中：

💡 附：康耐视 DataMan 读码器 FTP 存图参考设置页面
若现场同时使用 DataMan 系列读码器，在 DataMan Setup Tool 的 Image Transfer / Result FTP Transfer 页面填入上述服务器 IP、端口、用户名、密码及文件名规则即可：

二、康耐视 IS2800 相机 FTP 存图与动态命名配置

下面以 IS2800 相机配合 PROFINET 接收 PLC 下发的文件名并按 OK / NG 分类存图为例，介绍详细配置步骤。

1. 配置 PROFINET 通讯网络及站名

打开 In-Sight Vision Suite，先完成相机 IP、PROFINET 协议启用及站名配置：

2. 配置 Math 表格引入检测结果与存图路径变量

在 Math 表格中引入检测结果（如 OK / NG 判断），并拼接对应的目标文件夹名称或路径变量：

3. 配置通信选项卡参数

切换到 通信 选项卡，在右侧参数栏分别配置 工业通信协议、FTP 服务器地址及账号密码、存图路径：

3.1 通信协议数据映射（Format Data）

点击 Format Data 配置输入/输出数据：

  • 输入（PLC → 相机）：选定 写入图像 FTP → 文件名，数据类型设置为 字符串（String）（可用于接收 PLC 下发的条码 / 工件号作为图片名）；
  • 输出（相机 → PLC）：选择需要回传给 PLC 的视觉检测结果。

3.2 FTP 存图路径与动态文件夹设置

  1. 确认 FileZilla Server 中已创建对应账户并配置好本地共享根目录（如 C:\Users\...\Desktop\ftp）：

  1. 在相机的 FTP 文件路径 参数中引入第 2 步 Math 表格生成的目标文件夹名称变量（实现自动按 OK / NG 分目录存放），最后设定是否保存 重叠图形（SVG） 及文件名尾缀：

4. 图像存储效果验证

触发相机检测后，FTP 根目录下会自动生成分类文件夹（OK / NG），文件夹内同步保存原图（.bmp）及带检测框的叠加图（.svg）：

三、工控机存图定时自动清理脚本

产线相机长期高频拍照极易撑爆工控机磁盘，可将以下批处理脚本直接放在存图目录下，配合 Windows 任务计划程序 每日定时执行，仅保留最新的指定数量文件/文件夹。

版本 1：仅清理目录内的旧文件（不含子文件夹）

保存为 定时清理文件.bat（UTF-8 编码），按需修改 KEEP_FILE_COUNT（默认保留最新 5000 个文件）：

版本 2：同时清理旧文件及旧子文件夹（适合按日期分目录存图）

保存为 定时清理文件-含文件夹.bat，按需修改 KEEP_FILE_COUNT（例如按天分目录时可设为 30，保留最近 30 天目录）：

⚠️ 使用提醒：

  1. 脚本会对自身所在目录执行删除操作，请务必将其放入专门的 FTP 存图子目录中，切勿放在桌面或系统盘根目录直接运行！
  2. 建议通过 Windows 任务计划程序（Task Scheduler） 创建每日定时任务，指定「起始于」为脚本所在目录，实现无人值守自动清理。
