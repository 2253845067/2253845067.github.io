G120D变频器配置

发表于2026-04-12|更新于2026-04-12|工业自动化

安全注意事项

调试向导

准备工作

关键注意事项

  • 参数状态检查：如果变频器参数 P10 显示为“就绪”状态，在离线模式下将无法进行快速调试。

  • 解决方法：需要在实际参数列表中手动修改相关参数。

  • 例外情况：如果是直接离线进入调试向导，则无需进行此步骤。

  • 参数 P10 就绪状态示例

进入调试向导

按照屏幕指引，找到并点击左侧菜单栏中的“调试向导”选项，开始进行参数配置。

设定值指定

开环/闭环控制方式

I/O配置与报文配置

  • I/O默认配置设置：选择 I/O 的默认配置为7，对应参数P15。

  • 报文配置设置：将报文配置设置为999，对应参数P922。

标准与电压配置

  • 标准参数配置 (P100)：

    • 标准选择：0 (IEC标准)

    • 电源频率：50Hz

  • 电压参数配置 (P210)：

    • 设备输入电压：380V

    • 确保与现场实际供电情况一致

  • 功率单元应用 (P205)：

  • 标准选择：0（含重载）

  • 根据现场环境选择对应单元应用

电机参数配置

  • 关键配置参数列表：
    • P300[0] 选择1：异步电机类型
    • P133[0].0：设置电机连接方式
    • P304[0] / P305[0]：额定电压与电流
    • P307[0] /P308[0] / P310[0]：额定功率额定功率因素与与频率
    • P311[0]：电机额定转速
    • P335[0]：冷却方式（自冷却）
    • P601[0]：温度传感器（无）

电机铭牌参数参考

参数配置界面示例

电机抱闸制动配置

  • 关键参数配置项：
    • 参数 P1215：电机抱闸控制方式选择
    • 参数 P1216：抱闸打开时间设定 (ms)
    • 参数 P1217：抱闸闭合时间设定 (ms)

参考速度与斜坡配置

  • 最大转速配置：参数号：P322[0]
  • 斜坡上升时间：参数号：P1120 (设定值：1.2S)
  • 斜坡下降时间：参数号：P1121 (设定值：0.87S)
  • 急停斜坡时间：参数号：P1135 (设定值：0S)
  • 电流极限保护：参数号：P640 (设定值：电机额定电流P305[0]的1.5倍)

工艺应用与电机识别

  • 工艺应用配置 (P502)：设置参数 P502 以选择合适的工艺应用宏，确保变频器驱动模式与负载特性匹配。
  • 电机识别运行 (P1960)：启动参数 P1960 执行电机识别，使变频器自动检测并优化电机参数，为精确控制奠定基础。

安全通信与方向设置

  • 安全通信配置：此次为安全变频器走的安全通信，需要设定为通讯给定STO信号。

  • 安全测试停止时间调整：将安全测试停止时间修改为9000H,否则到时间需要经常断开STO才能不警告

  • F-DI/F-DO/PROFIsafe：安全地址转16#

参数下载与验收测试

  • 参数下载与零点校正：

    • 下载参数至变频器，原点自动校正至P2599数值。

    • 上传参数到组态并转在线。

    • 建议断电重启，测试零点位置是否正确。

  • 安全参数验收测试：

    • 配置安全参数若出现报错，需进行验收测试。

    • 测试结束后必须上传参数，否则下次下载需重新测试。

电机优化与静态测量

  • 电机优化与静态测量准备：参数配置完成后，需进入调试模式进行电机优化，重点进行静态优化设置。

  • 静态测量操作流程：选择“静态测量”方式并激活，切换至控制面板手动向前移动（非JOG模式），设定速度为0，等待测量提示完成，使能将自动断开。

  • 惯量计算与参数保存：测量完成后电机自动旋转计算惯量，参数固定后，务必将参数保存至EEPROM中以确保设置生效。

PMC数据反馈配置

  • 配置步骤说明：

    • 根据项目需求，需将变频器的实际电流数据反馈至PMC系统。

    • 具体操作：在通讯参数设置中，将12号预留字节设定为“实际电流反馈”。

电机曲线配置

  • 配置步骤说明：

    • 在信号栏选择所需要监控的曲线，点击红色方框进行监控
