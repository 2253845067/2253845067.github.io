SEW MOVI-C MOVIKIT Position Velocity配置向导

发表于2026-11-28|更新于2026-11-28|工业自动化

本文整理自 SEW-EURODRIVE 培训手册《MOVI-C Modular / System 多轴模块/系统模块 — MOVIKIT Position / Velocity 定位/速度控制模块配置向导（Version 2.0）》，适用于使用 MOVISUITE 软件对 MOVI-C 系统进行完整调试与上位 PLC 通讯组态的工程场景。

概述

编写目的

  • 熟悉并掌握 MOVISUITE 调试软件的基本操作；
  • 熟悉并掌握 MOVI-C Modular / System 模块使用 Position / Velocity MOVIKIT 软件模块的配置与调试方法。

补充参考文档

  • MOVI-C Modular 操作手册 (25953303.pdf)
  • MOVIKIT Position / Velocity 手册 (25951300.pdf)
  • MOVI-C UHX85A 手册 (22781455.pdf)
  • UHX85A PROFINET 手册 (22774254.pdf)

⚠️ 安全与免责提示：本教程仅作为培训及工程配置参考，不能替代官方操作手册。操作现场设备前，务必遵循对应硬件的操作手册与安全规范。

整体调试步骤总览

MOVIKIT Position / Velocity 的完整配置流程分为以下 9 个步骤：

  1. 了解现场设备，确认硬件安装和接线；
  2. 工程师电脑与现场 MOVI-C 设备建立通讯连接；
  3. 简单介绍 MOVI-C 调试软件（MOVISUITE）；
  4. 开始第一个轴的电机参数配置；
  5. 通过手动操作验证电机参数配置和优化；
  6. 开始第二个轴、第三个轴的电机参数配置和优化；
  7. 创建 UHX85A 内的 IEC 程序，自动生成程序代码；
  8. 添加 Fieldbus Monitor，监控和模拟 PLC 过程数据；
  9. 在西门子 PLC 内完成通讯组态与程序控制。

1 了解现场设备，确认硬件安装和接线

本章目标：了解变频器系统硬件组成，确认现场供电与接线状态。

1.1 了解设备

C 电机连接，采用 Harting 插头实现电机动力电缆连接

1.2 检查供电与接线

1.2.1 UHX85A 接线

  • 【1】：与 MOVISUITE 软件 / 工程师调试电脑接口 LAN3；
  • 【2】：现场总线接口 / PROFINET 总线接口 X21 / X22；
  • 【3】：EtherCAT / SBusPLUS 系统总线接口 LAN2。

⚠️ 注意：

  • LAN2：SBusPLUS 系统总线，接 MDP 功率模块的 X30 IN；
  • LAN3：EtherNet 接口，接工程师电脑；
  • X21 / X22：PROFINET 网口，接上位西门子 PLC。

1.2.2 MDP 功率模块与 MDD、MDA 轴模块接线

💡 提示：直流母排接线请参照官方手册进行，注意 24V 母排载流量以及轴模块排序——功率大的轴模块应排在靠近功率模块端，功率小的轴模块放在远离功率模块端。

现场需重点检查 STO 接线 和 网络接线（X30）：

  • 网络接线：X30 IN 为黑色，X30 OUT 为红色。

  • STO 端子接线：如现场使用 STO 安全功能，请拆除短接线，将 STO 回路连接到安全 PLC 或者安全继电器输出。

接线检查无误后，可将维修开关拨到 ON 位置，系统上电。此时应确认：

  • PLC 电源指示灯亮起；
  • MDP 功率模块强电指示灯亮起；
  • 轴模块指示灯亮起，数码管显示非 Exx.xx 故障代码（例如 C4、01 等）。

4.5 初次设定驱动器的动态特性参数

控制器动态特性主要包含 刚性 和 齿隙 两项参数：

1. 刚性（Stiffness）

衡量系统整体机械设计与连接刚度（常见范围 0.7 ~ 1.4）：

  • 刚性 > 1：机械连接紧固，可承受高加减速；
  • 刚性 < 1：机械连接较柔，需柔和加减速以防止末端晃动或震荡。
刚性建议值 常见系统描述 分类

0.9 ~ 1.1 普通硬齿面减速机或刚性联轴器驱动负载，刚性一般，不易晃动震荡 常规驱动系统

  • 2：输入 时钟脉冲长度（单次增量位移）；
  • 3：输入 增量停止时间（每次增量间隔停顿时间）；

  • 6：点击停止按钮（F4）停止运行；

  • 驱动寻参步骤：点击 a 打开设定选项，再点击 b（启动参考运行）完成寻参。
